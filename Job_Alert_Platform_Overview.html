1. Working of the Project (In Simple Terms)

The Job Alert Platform is an automated web application designed to collect student subscriptions, securely sync recipient lists, harvest verified IT job openings, and automatically dispatch personalized daily job newsletters to students' Gmail inboxes.

💡 Real-World Analogy (How it Works)

Imagine an automated digital newspaper service:

  • Admin Dashboard: The manager registers new subscribers (students) into the system.
  • Cloud Sync Engine: Locks the subscriber list into a secure cloud vault (GitHub Secrets).
  • Automated Mailer Engine: Every day, picks 20 fresh job openings, grabs a career quote, packages them into a styled HTML newsletter, and delivers them directly into each student's Gmail inbox.

2. Key Models Used in the System

1. User Authentication Data Model (SQLite: users)

Stores admin and system user credentials (username, Bcrypt-hashed password, role). Enforces Role-Based Access Control so only admins can manage student lists.

2. Student Subscriber Data Model (SQLite: students)

Stores student names, unique emails, and creation timestamps. Automatically calculates how many days a student has been active in the program.

3. Job Data Model (jobs.json)

Structured repository containing scraped IT job openings with titles (e.g. AI Engineer, Data Science Intern) and direct application links.

4. Sodium SealedBox Cryptographic Security Model (PyNaCl)

Asymmetric public-key encryption model. When student data changes, the app encrypts names and emails with GitHub's public key before uploading them to GitHub Repository Secrets.

5. Bcrypt One-Way Hashing & Token Models

Blowfish cipher hashing for passwords and signed timed serializers (1-hour expiration) for password reset links.

3. Step-by-Step Output Pipeline (Data Flow)

[Admin Dashboard] │ ▼ (Add/Update Student) [SQLite Database (users.db)] │ ▼ (PyNaCl SealedBox Encryption) [GitHub Repository Secrets (EMAIL_TO, STUDENT_NAMES)] │ ▼ (Triggered Execution) [Mailer Engine (mailer.py)] ──◄ Samples 20 Jobs from [jobs.json] + Quote │ ▼ (Generates Personalized HTML Cards) [Gmail SMTP Server (smtp.gmail.com:587)] │ ▼ [Student Gmail Inbox 📧] (Direct Apply Links Delivered!)
  1. Step 1 (Registration & Encryption): Admin adds a student via Flask web portal ➔ Record stored in SQLite ➔ sync_student_secrets() encrypts data using PyNaCl and sends it to GitHub Secrets.
  2. Step 2 (Data Preparation): mailer.py reads dynamic environment variables ➔ loads job bank ➔ selects 20 random jobs ➔ selects a career quote.
  3. Step 3 (Template Rendering): Generates responsive HTML email cards with styled "View & Apply" buttons customized with the recipient's name.
  4. Step 4 (SMTP Delivery): Establishes a TLS-encrypted SMTP connection with Gmail ➔ Dispatches personalized HTML emails.
